Wiz Rear Wheel Removal

  • Tools Required:

  • Flathead Screwdriver

  • 14mm Wrench

  • 13mm Socket

  • 8mm Socket

  • Needle Nose Pliers



Remove the plastic inserts from the swing arm covers using a flathead screwdriver.







Remove the swing arm covers using an 8mm socket to take out the scews and washers.





Remove the right and left swing arm covers.









Remove the rear brake adjusting nut using a 14mm wrench.







Remove the rear brake barrel by sliding it out of the lever.





Remove the rear brake cable spring.





Remove the cotter pin from the rear brake stay using needle nose pliers.









Remove the nut, washer, and bolt from the rear brake stay using a 13mm socket.





Pull the rear brake cable out of the brake drum backing plate.



Remove the rear axle retaining nuts using a 24mm wrench.





Remove the axle nut using a 24mm wrench.



Remove the axle bracket screw using an 8mm socket.



Slide the axle bracket off of the axle.









Repeat axle bracket removal for the left side.







Zip ties can be cut to create more slack on the motor wiring.





Pull rear wheel out of the swing arm.







Slide the right-side axle tab washer off the axle.



Remove the rear brake drum cover plate.











Reverse procedure steps to reinstall the rear wheel. Axle nuts should receive 35 ft/lb torque using a 24mm wrench.





Axle retaining nut should receive 30 ft/lb torque using a 24mm wrench.



Rear brake tension should be adjusted so that the wheel spins freely when the brake is not being applied.
