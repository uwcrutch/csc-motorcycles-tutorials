This tutorial was originally written for the FT750-26. The information in this tutorial is slightly different but still useful for all generations of our 26" Fat Tire electric bicycles.

 

Installation tutorial for installing steel fenders on a 26" FT750. Fenders come with all the necessary hardware for installation. Call us at (800) 884-4173.

Tools needed:

  • 8mm wrench
  • 10mm wrench
  • 8mm socket
  • 10mm wrench
  • 5mm Allen key
  • Phillips screwdriver
