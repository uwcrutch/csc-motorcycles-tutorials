TT250 NECK BEARING REPLACMENT



TOOLS REQUIRED:

  • 22mm Wrench

  • 17mm Wrench

  • 5mm Allen

  • 6mm Allen

  • 8mm Socket

  • 10mm Socket

  • 12mm Socket

  • 17mm Socket

  • Hammer

  • Motorcycle Jack

  • Phillips Screwdriver

  • Flathead Screwdriver



Lift the front wheel of the motorcycle using a motorcycle jack.



Remove the headlamp assembly mounts using a 5mm Allen.



Disconnect the headlamp electrical connector.







Protect the gas tank while removing the handlebar.



Remove the handlebar clamp using a 6mm Allen.







Remove the left-side zip ties.

Remove the right-side zip ties.

Disconnect the clutch cable from the clutch perch/lever.

Remove the dash mounts with an 8mm socket.





Loosen the top triple tree fork tube pinch bolts using a 10mm socket.



Loosen the lower triple tree fork tube pinch bolts using a 10mm socket.





Remove the axle nut using a 19mm socket.





Remove the brake caliper using a 12mm socket.











Remove the front axle.



Remove the fork guards using a Phillips screwdriver.







If needed to slide out the forks, remove the triple tree fork tube pinch bolts using a 10mm socket.











Remove the neck stem top bolt using a 22mm wrench.





Remove the top triple clamp.





Remove the steering adjuster using a large flathead screwdriver (or punch) and hammer.

Replace the bearings.



Replace the bearings.







Reassemble front end.
